# فيديو المقصد التعريفي — 58 ثانية

فيديو تعريفي للمشاركة في **معرض إدارة المرافق**، مبني بالكامل من كود (HTML + CSS)
بهوية المقصد البصرية، مما يعني أن أي تعديل على النص أو الأرقام يستغرق دقائق لا أيام.

## الملفات
| الملف | الوصف |
|---|---|
| `template.html` | مصدر الفيديو — المشاهد والحركة والنصوص |
| `نص-التعليق-الصوتي.md` | نص التعليق بالعامية السعودية مع التوقيت لكل مشهد |
| `build.py` | يضمّن الخطوط داخل الملف وينتج `film.html` |
| `record.mjs` | يسجّل الفيديو من المتصفح |
| `preview.mjs` | يصدّر صورة لكل مشهد للمراجعة |
| `fonts/` | Reem Kufi (عناوين) و Cairo (نصوص) — النطاق العربي فقط |

## إعادة الإنتاج

```bash
npm install playwright
python3 build.py                 # ينتج film.html بالخطوط المضمّنة
node record.mjs                  # ينتج raw.webm (58.5 ثانية)
ffmpeg -ss 1.30 -t 58.0 -i raw.webm \
  -vf "fps=30,fade=t=in:st=0:d=0.6,fade=t=out:st=57.2:d=0.8,format=yuv420p" \
  -c:v libx264 -preset slow -crf 20 -movflags +faststart -an almaqsd-intro-58s.mp4
```

## التعديل السريع

- **النصوص والأرقام:** داخل أقسام `<section class="scene">` في `template.html`
- **توقيت المشهد:** الخاصية `data-t` (بالثواني)
- **الألوان:** متغيرات `--gold` و `--ink` و `--slate` في أعلى الملف
- **المدة الكلية:** الثابت `DURATION` في السكربت

## الصوت

الفيديو **صامت بشكل مقصود** — يُضاف عليه التعليق الصوتي بعد تسجيله بصوت بشري
حسب النص المرفق. دمج الصوت:

```bash
ffmpeg -i almaqsd-intro-58s.mp4 -i voiceover.wav -i music.mp3 \
  -filter_complex "[2:a]volume=0.12[m];[1:a][m]amix=inputs=2:duration=first[a]" \
  -map 0:v -map "[a]" -c:v copy -c:a aac -b:a 192k -shortest almaqsd-intro-final.mp4
```
