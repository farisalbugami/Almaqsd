# فيديو المقصد التعريفي — 58 ثانية

فيديو تعريفي للمشاركة في **معرض إدارة المرافق**، مبني بالكامل من كود
(HTML + CSS) بهوية المقصد البصرية، مع صور مرخّصة من Adobe Stock
وموسيقى خلفية مولَّدة برمجياً.

**المواصفات:** 1920×1080 · 30 إطاراً/ثانية · H.264 + AAC · 58.0 ثانية

## الملفات

| الملف | الوصف |
|---|---|
| `template.html` | مصدر الفيديو — المشاهد والحركة والنصوص والتوقيت |
| `نص-التعليق-الصوتي.md` | نص التعليق بالعامية السعودية مع التوقيت وإرشادات التسجيل |
| `music.py` | يولّد الموسيقى الخلفية (سلم Dm، 58.6 ثانية، ذروة ‎−16 dBFS‎) |
| `build.py` | يضمّن الخطوط والصور والأيقونات وينتج `film.html` |
| `record.mjs` | يسجّل الفيديو من المتصفح |
| `preview.mjs` | يصدّر صورة لكل مشهد للمراجعة |
| `img/` | الصور + سجل تراخيص Adobe Stock |
| `fonts/` | Reem Kufi و Cairo — النطاق العربي فقط |

## إعادة الإنتاج

```bash
npm install playwright
pip install numpy

python3 music.py        # ينتج music.wav
python3 build.py        # ينتج film.html (نحو 10 ميغابايت بالصور المضمّنة)
node record.mjs         # ينتج raw.webm

ffmpeg -ss 1.30 -t 58.0 -i raw.webm -i music.wav \
  -filter_complex "[0:v]fps=30,fade=t=in:st=0:d=0.7,fade=t=out:st=57.1:d=0.9,format=yuv420p[v];\
[1:a]atrim=0:58,afade=t=in:st=0:d=1.5,afade=t=out:st=55.5:d=2.5[a]" \
  -map "[v]" -map "[a]" -c:v libx264 -preset slow -crf 20 \
  -c:a aac -b:a 192k -movflags +faststart -shortest almaqsd-intro-v2.mp4
```

> ملاحظة: `ffmpeg` المرفق مع Playwright لا يحتوي على مرمّزات (decode فقط).
> استخدموا ffmpeg النظامي: `apt-get install ffmpeg`.

## التعديل السريع

| ما تريد تغييره | أين |
|---|---|
| النصوص والأرقام | أقسام `<section class="scene">` في `template.html` |
| توقيت ظهور المشهد | الخاصية `data-t` (بالثواني) |
| المدة الكلية | الثابت `DURATION` في سكربت `template.html` |
| الألوان | متغيرات `--gold` و `--ink` و `--slate` في أعلى الملف |
| الصور | استبدلوا الملفات في `img/` ثم `python3 build.py` |
| الموسيقى | `CHORDS` و `BAR` في `music.py` |

## الصوت

الفيديو الحالي فيه **موسيقى خلفية فقط**. التعليق الصوتي يُسجَّل بصوت بشري
حسب النص المرفق، ثم يُدمج — الأمر جاهز في نهاية ملف النص.

الموسيقى مولَّدة برمجياً عند ذروة ‎−16 dBFS‎، أي أن هناك مساحة كافية
للتعليق فوقها دون تضارب.
